## Learning Path

A practical progression is:

1. Begin with **Hotel Hijack: Worst Western Intro**.
2. Learn the fundamentals with **Buffer Bites: Craft the Overflow**.
3. Practice cyclic patterns using **Cyclic Surge**.
4. Find relevant offsets with **Offset Hunter**.
5. Study stack and register behavior with **Stack Register Sleuth**.
6. Use **GDB Binary Sleuth** to strengthen binary-debugging skills.
7. Explore memory-layout concepts with **ASLR Roulette**.
8. Study NOP sled concepts through **NOP Drift**.
9. Continue with **Shellcode Sprint**.
10. Apply the concepts in **Drift to Root**, **Drift to Root 2**, and **Overflow to Root**.

## How to Use the Labs

Use these binary-exploitation and CTF labs only in environments where you have explicit authorization.

Recommended workflow:

1. Read the individual lab objective and requirements.
2. Understand the target binary and stated scope.
3. Analyze program behavior before testing.
4. Use debugging and controlled experimentation to understand memory state.
5. Record offsets, stack behavior, registers, and relevant observations.
6. Study the protection mechanisms represented by the challenge.
7. Test only against the authorized lab target.
8. Document your methodology and lessons learned.
